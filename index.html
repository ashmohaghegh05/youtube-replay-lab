Install in Chrome, no Web Store needed.

Replay Lab is a student project. Follow these steps to install it from GitHub.

  1. Open the Replay Lab GitHub repository .
  2. Click the green Code button and select Download ZIP.
  3. Extract the ZIP on your computer.
  4. In Chrome, open chrome://extensions and switch on Developer mode.
  5. Click Load unpacked and select the extracted folder containing manifest.json.
  6. Open a standard YouTube video . Replay Lab appears beside the player!

Your bookmarks and notes are saved locally in Chrome. No account, API key, or AI model needed.
